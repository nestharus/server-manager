# Scope Risk — INIT-008

## Verdict

`LOW`

## Summary

The proposal stays inside the INIT-008 boundary stated by `PHASE_5_INDEX.md`: VPC + VKE + Object Storage + state backend, author + plan, no apply. Anti-scope §7 explicitly enumerates every Phase 5 sister initiative (009–016) plus app-cluster provisioning, backward-compat shims, multi-channel onboarding, locking guarantees, restore drill, and `cleanup-state` tooling — no leaked artifacts, no silent assumptions left for downstream initiatives to inherit. The channel pivot is contained to platform-substrate fields (`region`, `network`, `cluster`, `state`); application-layer concerns (image tags, route prefixes, runtime secrets) are absent. Six slices is the synthesis-flagged high end, but each has a distinct artifact contract and local-only acceptance criteria; the count is proportionate, not a split signal.

## Slice-boundary judgement

- **SLICE-025 ↔ SLICE-026**: clean. 025 is doc/authority displacement (DECISIONS.md, README, stale plans/* docs); 026 introduces all new artifacts under `infra/schemas/`, `infra/channels/`, `infra/scripts/`. Zero file overlap beyond the harness.
- **SLICE-026 ↔ SLICE-027**: clean. 026 produces resolved channel JSON via the resolver script; 027 consumes resolved JSON into the OpenTofu template + per-channel root and deletes the old environment triad. Boundary is "channel data → channel-template parameterization."
- **SLICE-027 ↔ SLICE-028**: clean (see S7). Both touch `backend.tfbackend`, but as producer/handoff-doc, not redundancy. Different roots (`infra/roots/channels/dev/` vs `infra/bootstrap/state-backend/`).
- **SLICE-028 ↔ SLICE-029**: clean. 028 introduces bootstrap docs and lockfile; 029 consolidates harness assertions across *all* active roots (bootstrap + dev) plus channel schema validation. Folding 029 into 028 would force 028 to know about SLICE-027's dev root, inverting the dependency.
- **SLICE-029 ↔ SLICE-030**: thinnest seam (S8). 029 is mandatory no-credentials baseline; 030 is optional credentialed plan path. Different trust postures, different acceptance branches. Mergeable in implementation if 030's net-new work proves trivial; not required.

Six slices is right-sized. No two slices belong together; no slice's scope signals INIT-008 should split.

## Convergence statement

Scope is clean; proposal can proceed to hookpoint research.
