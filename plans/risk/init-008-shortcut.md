# Shortcut Risk — INIT-008

## Verdict

`LOW`

## Summary

The proposal does not compromise its stated purpose to claim done-ness. Every deferral has a named owner (INIT-009 for SOPS/age, INIT-011 for Buildkite/PR-preview, INIT-012 for ingress/DNS, the post-Phase-5 deployment initiative for cleanup-state/restore drill/multi-channel onboarding), every "not claimed" posture is explicitly enumerated rather than hidden (Section 2.12 locking, Section 2.10 bucket existence, Section 2.14 credential custody), and the Round 1–3 closure maps already retired the most plausible shortcut paths — depth-2 inheritance now has the `e2e-pr-1234.yaml` fixture, generated tfvars now have a byte-identical/canonical-JSON regen contract, the `endpoint_placeholder` and `endpoint_documentation` no-op fields are gone, and the fictional successor-initiative label was replaced with neutral post-Phase-5 phrasing. The channel pivot is honest: spawn proves the schema field rather than half-implementing PR previews, ephemeral keys are derived in `spawn_platform_channel.py` rather than stored, and `customer`/`internal`/named e2e channels are excluded by acceptance assertions (`test ! -e infra/channels/customer.yaml`), not by half-implementation. Findings below are observations that do not block convergence but are worth recording so they don't become real shortcuts under future change.

- **Round 3 H2 (depth-1 inheritance only)**: closed. `e2e-pr-1234.yaml` has `parent: e2e-from-dev` and SLICE-026 acceptance asserts both inherited-from-`dev` (`platform.region == "ewr"`) and inherited-from-`e2e-from-dev` (`cluster.label`) values plus the depth-2 child override (`tenant: pr-1234`) (proposal.md:228-230, 580-585, 1050).
- **Round 3 H3 (prose-only `endpoint_documentation` field)**: closed. The `state` object now has `bucket`, `key`, `region` only — no documentation/placeholder field (proposal.md:160-162, 1051).
- **Round 2 H1 (fictional successor label)**: closed. All deferrals now use neutral "post-Phase-5 deployment initiative" / "a separate initiative opened after Phase 5 converges" phrasing aligned with `PHASE_5_INDEX.md:40`.
- **Round 2 A1 (OpenTofu CLI pin)**: closed. README prerequisites name `1.11.5` and SLICE-029/SLICE-030 harness asserts `tofu version` major/minor `1.11` (proposal.md:452-457, 519-524, 745-748).
- **No-backwards-compatibility compliance**: `infra/environments/{dev,staging,production}/` deletion is explicit and complete; no aliases, symlinks, wrappers, or transitional readers; SLICE-027 asserts `test ! -d infra/environments` (proposal.md:119-127, 625-630, 633).

- **Hidden coupling to INIT-009+**: none found. No Flux annotations, no Buildkite agent assumptions, no Kong CRDs, no SOPS reads, no Authentik dependencies. The bootstrap and dev roots are self-contained.
- **Authority drift on D-decisions**: user decisions (channel pivot, dev-only first channel, manual custody, no locking claim, single-bucket with per-channel keys, post-Phase-5 successor for real channels) align with synthesis D1–D12 defaults and the rfqautomation reference shape; no contradictions between proposal claims and synthesis evidence.
