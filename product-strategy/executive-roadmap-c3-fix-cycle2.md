### R-23 (line 326) — Transition-branch list (Member status lifecycle)
**Status:** Deliberate exception.
**Rationale:** The content `active → suspended → active/departed; active → departed; departed → active` is state-machine notation in a labeled specification field (`**State transitions:**`), not narrative prose. `WRITING_SKILL_MASTER.md` bans triads and pseudo lists because list-shaped *prose* reads as rhetorical cadence — the failure mode is cadence, not counting. Arrow-notation state paths in a schema specification do not create rhetorical cadence; they are symbolic notation carrying irreducible branching information. The operating stance ("break rules on purpose when you can name the failure mode the rule prevents") applies: the prose-cadence failure mode is absent in state-machine notation.
