# Scope risk assessment — Chapter contracts

YOU are the scope assessor. Assess scope risk for the proposal.

## Input files
- `proposals/26-chapters-contract.md` — proposal
- `research/26-chapters-contract.md` — research
- `research/26-chapters-contract-needs.md` — synthesis

## Assessment criteria
1. Is the proposal appropriately sized for a contracts module?
2. Does it include service/repository logic?
3. Are the validation rules proportionate?
4. Does it create coupling to unbuilt subsystems?
5. Is anti-scope clear and sufficient?
6. Does it fit with later form/ticket contracts?

## Output
Write assessment to `risk/26-scope.md` with verdict, findings, recs.

## Rules
- Only modify `risk/26-scope.md`
- No code, no server inspection
